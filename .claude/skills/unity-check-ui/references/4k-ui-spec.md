# 4K UI 规范标准（3840×2160）

本文档定义 4K 分辨率下 Unity UI 元素的尺寸、字号和间距标准。所有数值以像素为单位。

---

## 1. 字号等级

| 等级 | 字号 (px) | 用途 | 示例 |
|------|-----------|------|------|
| H1 / 超大标题 | 72–96 | 主标题、页面标题 | "游戏设置"、"主菜单" |
| H2 / 大标题 | 56–72 | 面板标题、章节标题 | "音频设置"、"角色信息" |
| H3 / 中标题 | 40–56 | 区块标题、Tab 标签 | "基本参数"、"技能列表" |
| Body / 正文 | 28–36 | 正文内容、说明文字 | 段落文本、物品描述 |
| Label / 标签 | 24–28 | 字段标签、按钮文字 | "用户名"、"确认" |
| Caption / 辅助 | 20–24 | 辅助说明、脚注 | "按 Esc 关闭"、版权信息 |

---

## 2. 元素尺寸

### 按钮

| 类型 | 最小尺寸 (W×H) | 推荐尺寸 (W×H) |
|------|---------------|----------------|
| 主按钮（Primary） | 240×72 | 320×80 |
| 次要按钮（Secondary） | 200×64 | 240×72 |
| 小按钮 / 图标按钮 | 80×80 | 96×96 |
| 文本按钮 / 链接 | - | 高度 36–48 |

### 输入框

| 类型 | 高度 | 推荐宽度 |
|------|------|----------|
| 单行输入 | 56–64 | 320–600 |
| 多行输入 | ≥120 | 400–800 |
| 下拉框 | 56–64 | 240–400 |

### 图标

| 场景 | 尺寸 |
|------|------|
| 大图标（技能/头像） | 128×128 – 256×256 |
| 中图标（工具栏） | 64×64 – 96×96 |
| 小图标（列表内嵌） | 40×40 – 56×56 |

### 面板

| 类型 | 推荐宽度 | 推荐内边距 |
|------|----------|------------|
| 大面板（主内容区） | ≥2688（≥70% 屏宽） | 40–80 |
| 全屏面板 | 3840（全宽） | 40–80 |
| 弹窗 / 对话框 | 800–1200 | 32–48 |
| 侧边面板 | 360–480 | 24–40 |
| 卡片 | 320–480 | 20–32 |

> **大面板硬性规则**：作为页面主内容区域的大面板，宽度必须 ≥70% 屏幕宽度（3840×70% = 2688px），高度必须 ≥70% 屏幕高度（2160×70% = 1512px）。不符合的视为 🔴 严重违规。

---

## 3. 间距体系

| 级别 | 值 (px) | 用途 |
|------|---------|------|
| xs | 8 | 紧密元素间距（图标与文字） |
| sm | 16 | 同组元素间距（标签与输入框） |
| md | 24 | 组内间距（列表项之间） |
| lg | 40 | 区块间距（面板内分区） |
| xl | 64 | 大区块间距（面板之间） |
| 2xl | 96 | 页面级间距（主内容区到屏幕边缘） |

## 4. Canvas 配置

```yaml
Canvas:
  Render Mode: Screen Space Overlay
  
CanvasScaler:
  UI Scale Mode: Scale With Screen Size
  Reference Resolution: 3840 × 2160
  Screen Match Mode: Expand          # 或 Shrink，按需选择
  Match Width Or Height: 0.5         # 宽高等权重匹配
  Reference Pixels Per Unit: 100
```

## 5. 常见页面模式

### HUD / 常驻 UI

```
Canvas (3840×2160)
├── TopBar               高度: 96   (≤ 12% 屏高 = 259px)  Anchor: 顶部居中, SizeDelta: (0, 96)
│   ├── TitleText       字号: H2 (56–72)
│   └── IconButton      尺寸: 80×80
├── BottomBar            高度: 80   (≤ 12% 屏高 = 259px)  Anchor: 底部居中, SizeDelta: (0, 80)
│   └── ...
└── SidePanel            宽度: 400    Anchor: 左侧/右侧, SizeDelta: (400, 0)
    └── ...
```

> **顶栏/底栏硬性规则**：TopBar、BottomBar、TitleBar 等横向条状面板的高度不得超过屏幕高度的 12%（2160×12% = 259px）。超过的视为 🔴 严重违规。推荐高度 80–120px。

### 弹窗 / 对话框

```
ModalPanel               尺寸: 1000×700  Anchor: 居中
├── TitleBar             高度: 80        Anchor: 顶部拉伸
│   └── TitleText       字号: H2
├── ContentArea          弹性填充        LayoutElement: FlexibleHeight=1
│   └── BodyText        字号: Body (28–36)
└── ButtonBar            高度: 80        Anchor: 底部拉伸
    ├── CancelBtn        尺寸: 240×72
    └── ConfirmBtn       尺寸: 320×80
```

### 列表 / 滚动视图

```
ScrollView               填充父级        Anchor: 全屏拉伸
└── Content              
    └── VerticalLayoutGroup  spacing: md (24)
        ├── ListItem    高度: 96–120
        │   ├── Icon    尺寸: 64×64
        │   └── Label   字号: Label (24–28)
        ├── ListItem
        └── ...
```

## 6. 检查维度速查

| 维度 | 检查目标 |
|------|----------|
| Canvas 分辨率 | Reference Resolution = 3840×2160 |
| 大面板占比 | 主内容区域面板 ≥70% 屏幕宽高（≥2688×1512） |
| 条状面板高度 | TopBar/BottomBar/TitleBar ≤12% 屏高（≤259px） |
| 字号 | 按角色匹配字号等级表 |
| 按钮尺寸 | 不小于最小尺寸，优先推荐尺寸 |
| 间距 | 按间距体系检查 padding/spacing |
| 锚点 | 固定元素用单点锚点，填充元素用矩形锚点 |
| 可点区域 | 交互元素最小 80×80（4K 下的手指/鼠标精度） |
