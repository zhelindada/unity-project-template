# Dev Plan Output Template

以下为各阶段开发计划文档的标准模板。

---

## 00-overview.md 模板

```markdown
# 开发计划总览 — [游戏名称]

## 基础信息
- 日期: YYYY-MM-DD
- 来源 GDD: [路径]
- 计划版本: v1.0

## 阶段概览

| 阶段 | 目标 | 预估时长 | 人天合计 | 团队规模建议 |
|------|------|----------|----------|--------------|
| Pre-Production | 原型验证 + 技术奠基 | N 周 | N d | N 人 |
| Production P1 | 垂直切片 | N 周 | N d | N 人 |
| Production P2 | 全面内容制作 | N 周 | N d | N 人 |
| Alpha | 内容完整 + 内部测试 | N 周 | N d | N 人 |
| Beta | 打磨 + 外部测试 | N 周 | N d | N 人 |
| Gold | 认证 + 发布 | N 周 | N d | N 人 |
| **合计** | | **N 周** | **N d** | |

## 职能分布

| 职能 | 人天 | 占比 |
|------|------|------|
| 程序 | N d | N% |
| 美术 | N d | N% |
| 策划 | N d | N% |
| 音频 | N d | N% |
| QA | N d | N% |

## 关键路径

1. [任务 A] → [任务 B] → [任务 C] → ... → Gold
2. 关键路径长度: N 人天

## 里程碑

| 日期/周次 | 里程碑 | 验收标准 |
|-----------|--------|----------|
| W4 | 原型可玩 | 核心循环可试玩 |
| W12 | 垂直切片完成 | 一块内容可全通 |
| W30 | Alpha | 所有内容可全通 |
| W40 | Beta | 性能达标 |
| W48 | Gold | 平台认证通过 |

## 主要风险

| 风险 | 概率 | 影响 | 缓解措施 |
|------|------|------|----------|
| [风险 1] | 高/中/低 | 高/中/低 | [措施] |

## 推演假设
> 💡 假设: [列出所有关键假设]
```

## 各阶段模板 (01-06)

每个阶段文档使用以下结构：

```markdown
# [阶段名称] — [游戏名称]

## 阶段目标
[1-2 句总结]

## 时间段
开始: WX | 结束: WY | 周数: Z | 人天: N

## 准入标准
- [ ] [进入本阶段前必须完成的事项]

## 任务列表

### [职能分类 1]

| ID | 任务 | 描述 | 工时 (人天) | 不确定度 | 优先级 | 依赖 | 负责人建议 |
|----|------|------|-------------|----------|--------|------|------------|
| T001 | [任务名] | [简述] | 5-8d | 中 | P0 | - | [职能] |
| T002 | [任务名] | [简述] | 3-5d | 低 | P1 | T001 | [职能] |

### [职能分类 2]
...

## 阶段内里程碑

| 周次 | 里程碑 | 标准 |
|------|--------|------|
| WX+2 | [里程碑] | [验收条件] |

## 准出标准 (Quality Gate)
- [ ] [准出条件 1]
- [ ] [准出条件 2]

## 风险与缓解
| 风险 | 应对 |
|------|------|
| [阶段特有风险] | [缓解措施] |
```

```
## 关键路径可视化

```
[起点]
  │
  ├─→ [核心系统开发] ──→ [关卡制作] ──→ [集成测试] ──→ [Alpha]
  │                                                          │
  └─→ [管线搭建] ──→ [资产制作] ──→ [性能优化] ──→ [Beta] ──→ [Gold]

```
## 主要依赖链

1. 技术选型 → 管线搭建 → 核心系统 → 内容制作 → 集成 → 测试 → 发布
```
