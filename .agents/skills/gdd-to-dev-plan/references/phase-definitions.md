# Phase Definitions & Quality Gates

## Phase 1: Pre-Production

**目标**: 验证核心假设，确立技术基础，团队对齐。

**典型时长**: 总开发周期的 10-15%

### 包含任务类型
- 核心玩法原型（paper prototype 或可玩原型）
- 技术选型与验证（engine, render pipeline, key middleware）
- 美术风格探索与风格指南确立
- 项目管线搭建（CI/CD, asset pipeline, code standards）
- 团队组建与工具培训

### Quality Gate (准出标准)
- [ ] 核心玩法原型通过内部试玩验证
- [ ] 技术选型文档完成，关键风险已验证（如多人同步、大世界流式加载）
- [ ] 美术风格指南（Art Bible）已完成 1-2 个关键资产的验证
- [ ] CI/CD 管线可运行，至少能自动构建出可执行包
- [ ] 文件夹结构与命名规范确立
- [ ] 垂直切片（vertical slice）的范围已确定

### 产出物
- 可玩原型
- 技术选型与架构文档
- 美术风格指南
- 项目规范文档

---

## Phase 2: Production Phase 1 — Core

**目标**: 完成垂直切片——一块完整可玩的内容，验证全管线。

**典型时长**: 总开发周期的 20-25%

### 包含任务类型
- 核心 Gameplay 系统实现（移动、战斗、交互）
- 灰盒关卡（blockmesh/greybox）
- 核心 UI 框架搭建
- 主要角色/敌人占位资产
- 基础音频系统
- 存档系统基础实现

### Quality Gate
- [ ] 垂直切片可从头到尾游玩
- [ ] 核心 Gameplay 手感达标（经试玩验证）
- [ ] 所有核心系统至少处于 MVP 状态
- [ ] 灰盒关卡中敌人/触发器/收集品可正常运作
- [ ] 资产管线已验证（美术→引擎→游戏内）
- [ ] 性能在目标平台上可接受（允许未优化）

### 产出物
- 垂直切片可玩包
- 核心系统 MVP
- 灰盒关卡

---

## Phase 3: Production Phase 2 — Full Content

**目标**: 完成全部内容制作，所有系统功能完整。

**典型时长**: 总开发周期的 30-35%

### 包含任务类型
- 全部关卡制作（从灰盒到最终美术）
- 全部 Gameplay 系统实现
- 全部 UI 面板
- 全部角色/敌人/物品资产
- 全部音频资产
- 本地化框架集成
- 教程/新手引导实现

### Quality Gate
- [ ] 所有计划关卡可游玩
- [ ] 所有 Gameplay 系统功能完整
- [ ] 所有 UI 面板实现完毕
- [ ] 所有资产（2D/3D/音频/VFX）已导入
- [ ] 本地化框架就位（翻译文本可后续填充）
- [ ] 教程/引导流程可完整走通

### 产出物
- 完整游戏内容
- 全部资产
- 本地化框架

---

## Phase 4: Alpha

**目标**: 内容完整，可从头到尾通关，进入全面测试。

**典型时长**: 总开发周期的 10-15%

### 包含任务类型
- 全部关卡连接与流程打通
- 过场动画/叙事内容集成
- 全面内部 QA 测试
- Bug 集中修复
- 难度平衡初调
- 存档完整性验证

### Quality Gate
- [ ] 从头到尾可通关（不崩溃、不卡关）
- [ ] 所有主线任务/流程可完成
- [ ] 无已知的 A 类 Bug（崩溃/卡死/坏档）
- [ ] 本地化文本已填充（至少主要语言）
- [ ] 难度曲线经初调验证
- [ ] 存档/读档在全部关卡节点验证通过

### 产出物
- Alpha 可玩包
- Bug 追踪清单
- 难度平衡初调数据

---

## Phase 5: Beta

**目标**: 全面打磨，性能达标，准备外部测试。

**典型时长**: 总开发周期的 10-15%

### 包含任务类型
- 性能优化（帧率、内存、加载时间）
- 视觉打磨（VFX、灯光、后处理）
- 音频打磨（混音、空间音效）
- 手柄/外设适配
- 辅助功能（accessibility）实现
- 外部/封闭测试
- 最终本地化校对

### Quality Gate
- [ ] 全平台性能达标（详见 tech-design 性能目标表）
- [ ] 无已知 B 类以上 Bug
- [ ] 视觉打磨完成（最终灯光、后处理、VFX）
- [ ] 音频混音完成
- [ ] 辅助功能就位
- [ ] 外部测试反馈已收集并分类

### 产出物
- Beta 可玩包
- 性能测试报告
- 外部测试反馈汇总

---

## Phase 6: Gold

**目标**: 最终质量保证，平台认证，准备发布。

**典型时长**: 总开发周期的 5-10%

### 包含任务类型
- 最终 QA pass（全平台）
- 平台认证（Sony/Microsoft/Nintendo/Apple/Google）
- 最终本地化 QA
- 商店页面与营销资产
- 首日补丁准备
- 发布检查清单验证

### Quality Gate
- [ ] 全平台最终 QA pass
- [ ] 平台认证通过
- [ ] 本地化 QA 通过
- [ ] 商店资产就位
- [ ] 发布检查清单全部打勾
- [ ] 团队签署发布就绪

### 产出物
- Gold Master
- 认证通过证明
- 发布就绪检查清单
